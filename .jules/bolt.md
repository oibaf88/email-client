## 2025-03-09 - Batch IMAP FETCH queries
**Learning:** In IMAP applications, fetching message headers individually leads to an N+1 query problem, severely impacting load times for large folders like INBOX. IMAP `FETCH` supports comma-separated sequence numbers or UIDs (e.g. `UID FETCH 1,2,3 ...`), allowing efficient batch retrieval. The `imaplib` library in Python exposes this via `client.uid("FETCH", sequence, query)`. However, IMAP servers do not guarantee that the returned response items will be ordered to match the request sequence.
**Action:** Next time an IMAP integration is optimized, join lists of UIDs using commas before issuing a `FETCH` call to batch the operations, and always include `UID` in the fetch query string to ensure responses can be properly sorted afterward.
